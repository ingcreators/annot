# Annot brand assets — served copy

These SVGs are the public press-kit copies of the same files in
the repo's [`/brand`](https://github.com/ingcreators/annot/tree/main/brand)
directory.

Astro serves them as static assets so that the `/press` page can
link directly to each download. Update them by re-running the
copy step from `packages/marketing/scripts/sync-brand-assets.sh`
(forthcoming) when the source assets in `/brand` change.

The full brand kit, including dark-mode wordmark stacks and the
ingcreators parent-org marks, is in the repo's `/brand`
directory under the same Apache-2.0 licence as the codebase.
