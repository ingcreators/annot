Annot is open source under
[Apache-2.0](https://github.com/ingcreators/annot/blob/main/LICENSE).
PRs welcome — bug fixes, docs improvements, new annotation tools,
new storage backends. We're especially keen to grow the
Playwright-side recipes and the headless annotator's coverage of
the editor's tool surface.

## Topics

- [**Local setup**](./local-setup) — clone, install, run the
  web app + the headless tests.
- [**Sending a PR**](./pr-workflow) — branch convention,
  commit message style, what CI checks before merge.

## Code of conduct

Be kind. We follow the [Contributor Covenant](https://www.contributor-covenant.org/).

## Issue triage

Open issues at
[github.com/ingcreators/annot/issues](https://github.com/ingcreators/annot/issues).
Bugs with a reproduction (screenshot + reproduction steps) move
fastest. For larger features, prefer opening a discussion or
draft PR first — the
[`docs/plans/`](https://github.com/ingcreators/annot/tree/main/docs/plans)
folder is where we work out designs before code.

## Plan-first work

For anything bigger than a single-file fix, we write a plan doc
in `docs/plans/<slug>.md` before the implementation PR. The plan
lifecycle is:

1. **Draft** — under discussion
2. **Queued** — approved, waiting for capacity
3. **In progress** — work has started
4. **Done** — moved to `docs/plans/_done/`

See [`docs/plans/README.md`](https://github.com/ingcreators/annot/blob/main/docs/plans/README.md)
for the full lifecycle.
