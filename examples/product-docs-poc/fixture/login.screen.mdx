# Login screen (SC-001)

The screen where unauthenticated users enter their credentials.
Provisional implementation until the employee-ID migration
completes; retired after the SSO switchover.

<Screen id="login" src="./shots/login.png">

<Overlay match={{ role: "textbox", name: "Email" }} intent="required" number={1}>
**Email** — Enter your corporate email address.

- Required
- Up to 255 characters
- RFC 5322 email format
- Personal Gmail addresses are not allowed
</Overlay>

<Overlay match={{ role: "textbox", name: "Password" }} intent="required" number={2}>
**Password** — 8+ characters, mix of letters / digits / symbols.

> 3 consecutive failures lock the account for 30 minutes.
</Overlay>

<Overlay match={{ role: "checkbox", name: "Stay signed in" }} intent="info" number={3}>
**Stay signed in** — Tick to keep the session for 30 days.

Do not use on shared devices.
</Overlay>

<Overlay match={{ role: "button", name: "Sign in" }} intent="action" number={4}>
**Sign in button** — Click to issue `POST /api/auth/sign-in`.

On success, the user is routed to `/dashboard`.
</Overlay>

</Screen>

## Transitions

<Transition trigger={{ role: "button", name: "Sign in" }} on="auth-success" to="SC-002" />
<Transition trigger={{ role: "button", name: "Sign in" }} on="auth-failure" to="self">
  Show an error banner at the top of the screen.
</Transition>
