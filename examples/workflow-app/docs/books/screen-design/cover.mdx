# Workflow App — Screen Design

This document is the per-element spec for every screen in
the Workflow App. Each chapter pins down which interactive
elements live on the screen, their data type, whether they
are required, and any constraints that drive validation.

## How to read

Each chapter has one annotated screenshot followed by a
list of overlay callouts. Where the operation manual cares
about *what the user does*, this book cares about *what the
field accepts and what happens when validation fails*.

The chapters mirror the application's route table:

| ID | Screen |
|----|--------|
| SD-001 | Sign in |
| SD-002 | Menu (applicant + approver) |
| SD-003 | New application |
| SD-004 | Confirm application |
| SD-005 | Application submitted |
| SD-006 | Pending approvals |
| SD-007 | Review application |
| SD-008 | Decision recorded |
