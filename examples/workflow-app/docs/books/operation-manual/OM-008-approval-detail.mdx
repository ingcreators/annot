# Review application

Each pending application opens onto a full-width detail
screen. The approver sees the applicant, category, amount,
submission timestamp, and the free-form reason in a single
definition list, then either approves or rejects.

<Screen id="approval-detail" src="/shots/approval-detail.png">

<Overlay match={{ role: "heading", name: "Review application" }} intent="info" number={1}>
Page heading. The definition list below shows every field
the applicant submitted.
</Overlay>

<Overlay match={{ role: "textbox", name: "Decision comment (Optional)" }} intent="info" number={2}>
Optional free-form comment shared with the applicant after
the decision. Use it to explain a rejection or attach a

<Overlay match={{ role: "button", name: "Reject" }} intent="error" number={3}>

</Overlay>

<Overlay match={{ role: "button", name: "Approve" }} intent="success" number={4}>

the decision terminal with an "approved" badge.
</Overlay>
