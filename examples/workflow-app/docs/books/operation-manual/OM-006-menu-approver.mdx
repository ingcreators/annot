# Menu — Approver

After signing in as an approver, the menu shows a single
"Pending approvals" card. The badge in the corner of the
card reflects the queue depth.

<Screen id="menu-approver" src="/shots/menu-approver.png">

<Overlay match={{ role: "link", name: "Pending approvals" }} intent="action" number={1}>
Opens the approval queue. The badge inside the card shows
how many submissions are waiting for a decision.
</Overlay>

<Overlay match={{ role: "button", name: "Sign out" }} intent="info" number={2}>
Signs the approver out and returns to the login screen.
</Overlay>

</Screen>
