# Workflow App — Operation Manual

This manual walks an end user through every screen of the
Workflow App in the order it would be encountered. Two roles
share the app:

- **Applicant** — submits leave / expense / purchase
  requests.
- **Approver** — reviews submissions and records the
  approve / reject decision.

## How to read

Every screen has its own page. Each page shows an annotated
screenshot of that screen with numbered callouts; the
callouts are explained in the legend immediately below the
image. Follow the chapters in order to mirror a real session.

Chapters 1–5 cover the applicant journey
(login → menu → application → confirm → submitted).
Chapters 6–9 cover the approver journey
(menu → pending list → detail → decision).

## Companion documents

- **Screen Design** book — per-element spec aimed at
