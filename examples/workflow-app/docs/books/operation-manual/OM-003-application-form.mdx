# New application

Fill in the category, the requested amount (when applicable),
and the business reason. Every field is required — the Review
button shows per-field errors if anything is missing.

<Screen id="application-form" src="/shots/application-form.png">

<Overlay match={{ role: "combobox", name: "Category (Required)" }} intent="required" number={1}>
Choose one of Leave / Expense / Purchase. The Amount field
hides automatically for Leave applications.
</Overlay>

<Overlay match={{ role: "textbox", name: "Reason (Required)" }} intent="required" number={2}>
Free-form text. Approvers see this verbatim — include the
context they need to decide.
</Overlay>

<Overlay match={{ role: "button", name: "Review" }} intent="action" number={3}>
Validates the form. On success, transitions to the confirm
screen; on failure, the empty fields surface their error
message in place.
</Overlay>

<Overlay match={{ role: "link", name: "Back" }} intent="info" number={4}>
Returns to the menu without submitting. The draft is kept in
memory — re-opening the form restores the partially-filled
state until the user signs out.
</Overlay>

</Screen>
