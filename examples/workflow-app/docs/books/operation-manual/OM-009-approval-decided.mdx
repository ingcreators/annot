# Decision recorded

After Approve or Reject, the approver lands on a terminal
screen that summarises the decision. The applicant sees the
new status when they next open their menu.

<Screen id="approval-decided" src="/shots/approval-decided.png">

<Overlay match={{ role: "heading", name: "Application approved" }} intent="success" number={1}>
The heading reads "Application approved" or "Application
rejected" depending on the decision. The screenshot here
shows the approved variant.
</Overlay>

<Overlay match={{ role: "button", name: "Back to pending list" }} intent="action" number={2}>
Returns to the queue. The just-decided item is removed from
the pending list — the queue badge in the menu reflects the
new depth.
</Overlay>

</Screen>
