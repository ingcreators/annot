# Launch copy drafts

> **Status:** Drafted, not yet published. Phase 8f of
> [`docs/plans/launch-prep.md`](../plans/launch-prep.md).

This directory is the **staging ground** for the public copy we
publish at launch — Show HN post, blog post, ready-to-paste
social media posts, Product Hunt submission. The drafts live
here so we can iterate on wording in version control before
posting them.

**Nothing in this directory is auto-published.** When launch day
arrives, the operator copy-pastes each draft into the live
channel (HN, the blog, Twitter, Bluesky, Product Hunt).

## Operator action

When ready to launch:

1. Pick a launch day — **Tuesday or Wednesday, 09:00 PT** is the
   conventional Show HN sweet spot.
2. Schedule the Product Hunt submission for **00:01 PT** the
   same day (PH ranks by 24-hour score from posting time).
3. Tweet / post within the first 30 minutes after the Show HN
   goes up — use `social-posts.md` post #1 first.
4. Hold the blog post until day 2 — link it from the Show HN
   thread when the discussion warms up.
5. Use the remaining social posts on days 2-5 as follow-ups.

## Editing posture

These are **drafts**. Edit freely until the operator copies them
to the live channel. Once posted, the live version is the
canonical text — any further changes to wording happen in the
live channel only.

The repo copy is preserved as historical context (what we
believed the value prop was at launch). Don't update the repo
draft to reflect post-launch wording corrections — that would
rewrite the launch-time narrative.
