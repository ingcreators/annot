Set up your first capture

This guide walks through the initial capture-and-annotate flow. Each step shows the screen state to compare against.

Initial setup

Install the browser extension

Pin Annot to your toolbar so the capture button is one click away.

Grant page-capture permission

Confirm the permission prompt the first time you capture a page.

Verification

Open the gallery

The captured image appears in the gallery thumbnail strip. Click it to start annotating.

If the capture button is greyed out, reload the page and re-grant permission.
